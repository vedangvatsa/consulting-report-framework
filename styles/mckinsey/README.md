# McKinsey BVOD Consulting Report Style

A formal executive digital briefing style modeled on McKinsey & Company's *The Business Value of Design (BVOD)*.

- **Geometry**: A4 Landscape (`297mm × 210mm`)
- **Typography**: Newsreader Serif (Headlines, Numerals, Quotes) + Inter Sans (Body, Exhibits)
- **Palette**: Charcoal Ink (`#111827`), Warm Paper (`#fafaf9`), McKinsey Cobalt Blue (`#0038FF`), Steel (`#4b5563`)
- **Structure**: Two-Tier Layout (Empirical Top Tier + Operational Framework Bottom Tier + Takeaway Strip)
- **Components**: `components.mjs`
- **Engine**: `engine.mjs`
- **CLI**: `cli.mjs`
